# HPC Cluster - Woodwell Climate Research Center

This repository contains the code for deploying the HPC cluster for different teams.

Each team has different requirements so the configuration of each team is a little bit different.
One can see the code for each team by switching to the related branch:

- [Arctic](https://github.com/whrc/hpc-cluster/tree/arctic)
- [Carbon](https://github.com/whrc/hpc-cluster/tree/rangelands)
- [Risk](https://github.com/whrc/hpc-cluster/tree/risk)
